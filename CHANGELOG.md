# Changelog

## 0.1.0 (2026-09-30)

First public release of the 2D-3D Knowledge Graph Package by Hung Ngo.

- **2D Knowledge Graph:** a Links and Graphify source switch; filters, Colour by, groups, display, Hubs mode and forces; force animation; opens a Graphify node's note at the passage.
- **3D Knowledge Graph:** the same sources in 3D, with hover highlight, particles, labels, the local graph (depth 1–4) and orbit controls.
- **3D Semantic Graph:** clusters, colour categories, scopes, search by meaning, closest notes, and a settings panel with spread.
- `createHost` and `createStaticSemantic` (search and neighbours run in the browser from packed vectors).
- React and Vue components, and standalone scripts for plain HTML and iOS/macOS web views.
- Installed straight from GitHub (`npm install github:hungnv26/2d-3d-knowledge-graph`); `dist/` is committed.
- Tools: `kg-links`, `kg-graphify` and `tools/semantic/build.py`.
- Sample data *The Meridian Archive*, a demo site, JSON Schemas, `AGENTS.md`, `llms.txt` and a Claude Code skill.
