# Chief Aurelio Takeda


The archive remembers Chief Aurelio Takeda for more than the service record says. Somewhere in the core a subroutine hesitated. The telemetry told a calmer story than the crew, and ORRERY was never far from anyone's mind.

Aurelio Takeda’s field journal came up in every debrief afterwards. The survey team spent a week on Aurelio Takeda’s commendation alone. The crew learned about core memory lattice the hard way.
