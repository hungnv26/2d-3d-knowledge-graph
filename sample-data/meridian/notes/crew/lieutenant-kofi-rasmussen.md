# Lieutenant Kofi Rasmussen


Lieutenant Kofi Rasmussen joined the Meridian in the second year and never quite left. Someone had strung lights along the corridor again. Letters from home were read aloud, twice, and the captain’s table was never far from anyone's mind.

Most of the arguments aboard came back to Kofi Rasmussen’s last posting. The crew learned about Kofi Rasmussen’s command style the hard way. The crew learned about the midwatch supper the hard way. Nobody agreed on what the memory wall really meant.
