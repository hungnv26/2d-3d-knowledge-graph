# Ensign Arjun Rasmussen


The archive remembers Ensign Arjun Rasmussen for more than the service record says. The derelict gave up its parts without complaint. The hull held because someone refused to let it fail, and the junkyard fleet was never far from anyone's mind.

Arjun Rasmussen’s last posting came up in every debrief afterwards. The notes on Arjun Rasmussen’s commendation run to several pages. Nobody agreed on what hull mending really meant. The notes on structural fatigue run to several pages.
