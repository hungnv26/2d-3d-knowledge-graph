# Ovteth III


Nobody forgets their first approach to Ovteth III. The map was redrawn for the ninth time. The survey drone came back with more questions, and lensed horizons was never far from anyone's mind.

The notes on the Ovteth III beacon run to several pages. Ovteth III storm cycle came up in every debrief afterwards. Most of the arguments aboard came back to Ovteth III landing site. The crew learned about dust rivers the hard way. Gravity shoals came up in every debrief afterwards. ORRERY flagged drift charts before anyone else noticed it.
