# Ember Fields


Charts list Ember Fields as a frozen world along the Vell Drift. The builders had left, carefully, on purpose. The doorway opened at a hum only the ship could make, and buried observatories was never far from anyone's mind.

Most of the arguments aboard came back to the Ember Fields beacon. The notes on the Ember Fields rift run to several pages. The crew learned about Ember Fields tidal lock the hard way. The lantern script came up in every debrief afterwards.
