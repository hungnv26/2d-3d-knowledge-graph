# Vesny IX


Vesny IX sits deep in the Oru system, and the first survey team called it beautiful. The glyphs were older than the star that lit them. Every chamber faced the same distant point, and the patient architecture was never far from anyone's mind.

The survey team spent a week on Vesny IX tidal lock alone. ORRERY flagged Vesny IX landing site before anyone else noticed it. The notes on the drowned library run to several pages. The notes on spiral glyphs run to several pages. Keystone engines is still an open question in the archive.
