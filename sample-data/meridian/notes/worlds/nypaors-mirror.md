# Nypaor's Mirror


Charts list Nypaor's Mirror as a storm world inside the Lantern Belt. Three beacons flickered where there should have been four. The charts ended and the dark began, and waypoint decay was never far from anyone's mind.

The notes on Nypaor's Mirror tidal lock run to several pages. Nypaor's Mirror landing site is still an open question in the archive. Most of the arguments aboard came back to waypoint decay. The notes on lensed horizons run to several pages.
