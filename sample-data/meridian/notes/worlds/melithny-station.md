# Melithny Station


Nobody forgets their first approach to Melithny Station. The glyphs were older than the star that lit them. The builders had left, carefully, on purpose, and the lantern script was never far from anyone's mind.

Nobody agreed on what Melithny Station tidal lock really meant. The notes on the Melithny Station rift run to several pages. The Melithny Station beacon came up in every debrief afterwards. The notes on Melithny Station magnetosphere run to several pages. The notes on star-map murals run to several pages. The survey team spent a week on spiral glyphs alone.

The builders had left, carefully, on purpose. The doorway opened at a hum only the ship could make.
