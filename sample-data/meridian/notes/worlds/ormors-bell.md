# Ormor's Bell


Charts list Ormor's Bell as a garden world at the edge of the Outer Reach. Nobody spoke first, by design. A single prime number blinked back, and the first question was never far from anyone's mind.

The crew learned about the Ormor's Bell beacon the hard way. Ormor's Bell storm cycle came up in every debrief afterwards. The notes on observer drift run to several pages.

Compare the account in [[operation-whisperfield-v|Operation Whisperfield V]]. This connects to [[spore-shield|Spore shield]] in ways that are still being argued over.

Further reading: *Shared-Zero Mathematics* (Carrow, 2182).
