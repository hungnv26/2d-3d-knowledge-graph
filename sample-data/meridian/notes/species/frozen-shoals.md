# Frozen Shoals


Frozen Shoals are beautiful to watch and harder to classify. The Vell spoke only when the wind agreed. The council drifted apart and together like cloud, and the gift exchange was never far from anyone's mind.

Frozen Shoals life cycle is still an open question in the archive. Nobody agreed on what Frozen Shoals courtship lights really meant. The notes on the slow treaty run to several pages. The drifter council came up in every debrief afterwards. The notes on wind-reading run to several pages.

This connects to [[operation-ironveil-iii|Operation Ironveil III]] in ways that are still being argued over. The same pattern showed up at [[orrery|ORRERY]].
