# Null Choir


The archive keeps more questions than answers about the Null Choir. The instruments reported nothing, perfectly. The crew spoke in whispers without deciding to, and unspoken orbit was never far from anyone's mind.

Most of the arguments aboard came back to Null Choir migration. The notes on Null Choir venom run to several pages. Null Choir nesting grounds came up in every debrief afterwards. The survey team spent a week on null choir alone.

[[survey-of-the-silent-cluster|Survey of the Silent Cluster]] tells the other side of the story. See also [[stillwater-deep|Stillwater Deep]]. Compare the account in [[stillwater-ring|Stillwater Ring]].
