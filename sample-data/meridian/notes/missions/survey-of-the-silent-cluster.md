# Survey of the Silent Cluster


Survey of the Silent Cluster was logged as lost in 2192. An hour was missing from every clock aboard. No signal came back, not even static, and null choir was never far from anyone's mind.

The notes on the Silent Cluster casualty report run to several pages. The Silent Cluster debrief came up in every debrief afterwards. The notes on the Silent Cluster objective run to several pages. The crew learned about the Silent Cluster landing party the hard way. Most of the arguments aboard came back to the quiet wound.
