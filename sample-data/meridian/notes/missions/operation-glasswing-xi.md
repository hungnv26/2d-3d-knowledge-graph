# Operation Glasswing XI


Operation Glasswing XI was logged as planned in 2188. A gift was returned, which meant everything. The council drifted apart and together like cloud, and Vell migration law was never far from anyone's mind.

The notes on Glasswing XI objective run to several pages. Glasswing XI debrief came up in every debrief afterwards. Most of the arguments aboard came back to the drifter council.
