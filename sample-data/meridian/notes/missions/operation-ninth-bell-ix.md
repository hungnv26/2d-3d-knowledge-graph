# Operation Ninth Bell IX


Operation Ninth Bell IX was logged as lost in 2194. Every chamber faced the same distant point. The doorway opened at a hum only the ship could make, and the lantern script was never far from anyone's mind.

Ninth Bell IX objective came up in every debrief afterwards. The crew learned about Ninth Bell IX supply manifest the hard way. Ninth Bell IX casualty report came up in every debrief afterwards. Nobody agreed on what Ninth Bell IX landing party really meant. ORRERY flagged the drowned library before anyone else noticed it. The third inscription came up in every debrief afterwards. The notes on spiral glyphs run to several pages.
