# Morka Station Quarantine


Morka Station Quarantine began, like most missions, with a bad map and good intentions. Something below the shelf answered in light. Samples sang faintly in their jars, and silica shells was never far from anyone's mind.

The notes on Morka Station debrief run to several pages. Nobody agreed on what Morka Station objective really meant. The crew learned about Morka Station supply manifest the hard way. ORRERY flagged hydrothermal gardens before anyone else noticed it. ORRERY flagged shoal mind before anyone else noticed it.
