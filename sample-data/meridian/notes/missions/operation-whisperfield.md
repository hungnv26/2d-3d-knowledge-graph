# Operation Whisperfield


The board marked Operation Whisperfield succeeded in 2191, which only tells half of it. The glyphs were older than the star that lit them. Every chamber faced the same distant point, and resonant doors was never far from anyone's mind.

ORRERY flagged Whisperfield landing party before anyone else noticed it. ORRERY flagged Whisperfield casualty report before anyone else noticed it. Whisperfield supply manifest is still an open question in the archive. ORRERY flagged chronolith before anyone else noticed it.
