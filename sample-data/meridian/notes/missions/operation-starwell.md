# Operation Starwell


Operation Starwell was logged as lost in 2193. Three beacons flickered where there should have been four. The map was redrawn for the ninth time, and orbital census was never far from anyone's mind.

The crew learned about Starwell supply manifest the hard way. The notes on Starwell objective run to several pages. The survey team spent a week on Starwell casualty report alone. ORRERY flagged the dark meridian before anyone else noticed it. The crew learned about parallax ladders the hard way.

**Why the starwell crew rotates every watch.** The map was redrawn for the ninth time; the crew learned this the hard way, and wrote it down so the next crew would not have to.

The charts ended and the dark began. The map was redrawn for the ninth time.
