# Rescue at Nyzorkir's Mirror


The board marked Rescue at Nyzorkir's Mirror succeeded in 2192, which only tells half of it. The Vell spoke only when the wind agreed. The treaty was written in weather, not ink, and hospitality rites was never far from anyone's mind.

ORRERY flagged Nyzorkir's Mirror objective before anyone else noticed it. The notes on Nyzorkir's Mirror debrief run to several pages.
