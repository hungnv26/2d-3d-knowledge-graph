# Venthal's Orchard Quarantine


The board marked Venthal's Orchard Quarantine failed in 2191, which only tells half of it. Sickbay went quiet in the way that frightened everyone. The serum held, barely, and bone-density drift was never far from anyone's mind.

Nobody agreed on what Venthal's Orchard objective really meant. The crew learned about Venthal's Orchard landing party the hard way. The crew learned about decontamination arch the hard way. The crew learned about radiation burn protocol the hard way.
