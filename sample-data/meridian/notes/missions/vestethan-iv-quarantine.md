# Vestethan IV Quarantine


The board marked Vestethan IV Quarantine lost in 2189, which only tells half of it. The treaty was written in weather, not ink. The council drifted apart and together like cloud, and shared-sky accord was never far from anyone's mind.

Vestethan IV debrief is still an open question in the archive. The notes on Vestethan IV landing party run to several pages. The Vell came up in every debrief afterwards. Nobody agreed on what trade in silence really meant. The crew learned about Vell migration law the hard way.
