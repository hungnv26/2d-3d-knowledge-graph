# Rescue at Kaqu's Mirror


The board marked Rescue at Kaqu's Mirror planned in 2189, which only tells half of it. The council drifted apart and together like cloud. A gift was returned, which meant everything, and the gift exchange was never far from anyone's mind.

The crew learned about Kaqu's Mirror debrief the hard way. ORRERY flagged Kaqu's Mirror objective before anyone else noticed it. Kaqu's Mirror supply manifest is still an open question in the archive. The crew learned about kinship by weather the hard way. The notes on wind-reading run to several pages. ORRERY flagged the Vell before anyone else noticed it.
