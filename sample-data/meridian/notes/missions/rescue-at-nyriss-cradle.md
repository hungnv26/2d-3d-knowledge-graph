# Rescue at Nyris's Cradle


The board marked Rescue at Nyris's Cradle active in 2194, which only tells half of it. Every chamber faced the same distant point. The builders had left, carefully, on purpose, and chronolith was never far from anyone's mind.

The notes on Nyris's Cradle supply manifest run to several pages. Nobody agreed on what Nyris's Cradle casualty report really meant. Most of the arguments aboard came back to Nyris's Cradle debrief. The notes on resonant doors run to several pages. The survey team spent a week on the lantern script alone.

This connects to [[limxansel-station|Limxansel Station]] in ways that are still being argued over. [[ciithul-ix|Ciithul IX]] tells the other side of the story. The same pattern showed up at [[the-drowned-shelf-of-tethzorven|The Drowned Shelf of Tethzorven]]. See also [[the-singing-deeps-of-kirdar|The Singing Deeps of Kirdar]]. The same pattern showed up at [[operation-ninth-bell-ix|Operation Ninth Bell IX]]. This connects to [[navigator-ingrid-solberg|Navigator Ingrid Solberg]] in ways that are still being argued over.

**Why the nyris's cradle is never run unattended.** Every chamber faced the same distant point; the crew learned this the hard way, and wrote it down so the next crew would not have to.
