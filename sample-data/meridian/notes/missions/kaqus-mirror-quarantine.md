# Kaqu's Mirror Quarantine


The board marked Kaqu's Mirror Quarantine succeeded in 2190, which only tells half of it. The map was redrawn for the ninth time. The charts ended and the dark began, and waypoint decay was never far from anyone's mind.

Most of the arguments aboard came back to Kaqu's Mirror landing party. Kaqu's Mirror casualty report came up in every debrief afterwards. Nobody agreed on what orbital census really meant. Nobody agreed on what the long survey really meant.

The map was redrawn for the ninth time. Three beacons flickered where there should have been four.
