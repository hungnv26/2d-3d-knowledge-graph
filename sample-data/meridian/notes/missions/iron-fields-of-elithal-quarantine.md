# Iron Fields of Elithal Quarantine


The board marked Iron Fields of Elithal Quarantine lost in 2193, which only tells half of it. Every chamber faced the same distant point. The doorway opened at a hum only the ship could make, and the third inscription was never far from anyone's mind.

Most of the arguments aboard came back to Iron Fields of Elithal debrief. ORRERY flagged Iron Fields of Elithal objective before anyone else noticed it. ORRERY flagged Iron Fields of Elithal supply manifest before anyone else noticed it. The notes on Iron Fields of Elithal landing party run to several pages. Nobody agreed on what harmonic masonry really meant.
