# Incident Report: Silent Landing (2187)


Recorded during the midwatch; some words are lost to static. Laughter carried further than it should in the low gravity. Someone had strung lights along the corridor again, and shore-leave lottery was never far from anyone's mind.

Silent Landing timeline came up in every debrief afterwards. The notes on the Silent Landing alarm run to several pages. The crew learned about Silent Landing witness account the hard way. Shore-leave lottery is still an open question in the archive. The crew learned about the captain’s table the hard way. Nobody agreed on what the memory wall really meant.

Compare the account in [[captain-tallulah-rasmussen|Captain Tallulah Rasmussen]]. The same pattern showed up at [[survey-of-vesves-vii|Survey of Vesves VII]]. Compare the account in [[captain-ines-vantablack|Captain Ines Vantablack]]. Crew who worked on [[navigator-tallulah-yilmaz|Navigator Tallulah Yilmaz]] disagreed.

**Why the silent landing must idle before a jump.** Letters from home were read aloud, twice; the crew learned this the hard way, and wrote it down so the next crew would not have to.
