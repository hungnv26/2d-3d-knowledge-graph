# Incident Report: Fold Stall (2189)


Recorded during the midwatch; some words are lost to static. The telemetry told a calmer story than the crew. The ship corrected itself before anyone noticed, and command handshake was never far from anyone's mind.

The crew learned about the Fold Stall alarm the hard way. The notes on Fold Stall timeline run to several pages. ORRERY is still an open question in the archive. Most of the arguments aboard came back to the quiet subroutine.

[[hull-furnace|Hull furnace]] tells the other side of the story. Compare the account in [[tidal-mender|Tidal mender]].

**Why the fold stall was retired.** The telemetry told a calmer story than the crew; the crew learned this the hard way, and wrote it down so the next crew would not have to.

ORRERY logged the decision and, unusually, its doubt. The ship corrected itself before anyone noticed.
