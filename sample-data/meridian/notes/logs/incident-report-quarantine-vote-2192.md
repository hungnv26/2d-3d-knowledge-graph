# Incident Report: Quarantine Vote (2192)


Recorded during the midwatch; some words are lost to static. The telemetry told a calmer story than the crew. ORRERY logged the decision and, unusually, its doubt, and the soft override was never far from anyone's mind.

The survey team spent a week on the Quarantine Vote alarm alone. Quarantine Vote aftermath is still an open question in the archive. The crew learned about Quarantine Vote timeline the hard way. ORRERY flagged Quarantine Vote witness account before anyone else noticed it. The notes on the orrery dream run to several pages.
