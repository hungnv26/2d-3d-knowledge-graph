# ORRERY Core Index


An index, kept by ORRERY and corrected by hand. The ship corrected itself before anyone noticed. ORRERY logged the decision and, unusually, its doubt, and ORRERY was never far from anyone's mind.

ORRERY flagged the ninth fallback before anyone else noticed it. Empathy module is still an open question in the archive. The crew learned about deferred obedience the hard way. Most of the arguments aboard came back to sensor ghosts. The quiet subroutine is still an open question in the archive.
