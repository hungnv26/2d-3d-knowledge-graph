# Crew Manifest


An index, kept by ORRERY and corrected by hand. Letters from home were read aloud, twice. Laughter carried further than it should in the low gravity, and the captain’s table was never far from anyone's mind.

Most of the arguments aboard came back to the memory wall. The survey team spent a week on the chess ladder alone. The notes on watch rotation run to several pages. Grief rotation is still an open question in the archive. ORRERY flagged birthday protocol before anyone else noticed it.
