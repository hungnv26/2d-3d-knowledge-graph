# Memory scrubber


The Memory scrubber was fitted during the second refit and never fully trusted. The charts ended and the dark began. Three beacons flickered where there should have been four, and the cartographer’s error was never far from anyone's mind.

Memory scrubber safety interlock is still an open question in the archive. Nobody agreed on what Memory scrubber calibration really meant. Nobody agreed on what beacon chains really meant. ORRERY flagged waypoint decay before anyone else noticed it.
