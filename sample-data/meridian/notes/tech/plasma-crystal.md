# Plasma crystal


Every engineer aboard has an opinion about the Plasma crystal. Water was the only currency that mattered. Every leaf was counted twice, and root rot crisis was never far from anyone's mind.

The crew learned about Plasma crystal safety interlock the hard way. Most of the arguments aboard came back to Plasma crystal calibration. Nobody agreed on what Plasma crystal prototype really meant. The long harvest came up in every debrief afterwards. The notes on nutrient cascade run to several pages. The notes on seed vault run to several pages.

See also [[watch-log-2194-157|Watch Log 2194.157]]. [[star-scrubber|Star scrubber]] tells the other side of the story. The same pattern showed up at [[echo-sail|Echo sail]]. This connects to [[tidal-cradle|Tidal cradle]] in ways that are still being argued over.

**Why the plasma crystal was retired.** Water was the only currency that mattered; the crew learned this the hard way, and wrote it down so the next crew would not have to.
