# Memory sail


The Memory sail is the kind of machine that works perfectly until it becomes a story. The serum held, barely. Sickbay went quiet in the way that frightened everyone, and the immunity map was never far from anyone's mind.

The crew learned about Memory sail failure mode the hard way. ORRERY flagged Memory sail power draw before anyone else noticed it. Most of the arguments aboard came back to radiation burn protocol. Field surgery came up in every debrief afterwards. The survey team spent a week on the immunity map alone.

The serum held, barely. The fever broke on the ninth day.
