# Spore loom


The Spore loom was fitted during the second refit and never fully trusted. The ship corrected itself before anyone noticed. ORRERY logged the decision and, unusually, its doubt, and hull telemetry was never far from anyone's mind.

The crew learned about Spore loom calibration the hard way. The notes on Spore loom prototype run to several pages. The notes on Spore loom safety interlock run to several pages. The notes on Spore loom power draw run to several pages. Core memory lattice came up in every debrief afterwards.
