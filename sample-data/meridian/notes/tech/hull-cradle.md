# Hull cradle


The Hull cradle was fitted during the second refit and never fully trusted. Sickbay went quiet in the way that frightened everyone. The serum held, barely, and cryo triage was never far from anyone's mind.

Hull cradle prototype is still an open question in the archive. The notes on Hull cradle calibration run to several pages. Hull cradle power draw is still an open question in the archive. The crew learned about the Halvorsen serum the hard way.
