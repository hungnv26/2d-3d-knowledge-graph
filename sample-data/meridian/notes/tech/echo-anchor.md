# Echo anchor


Every engineer aboard has an opinion about the Echo anchor. ORRERY logged the decision and, unusually, its doubt. The telemetry told a calmer story than the crew, and predictive maintenance was never far from anyone's mind.

Nobody agreed on what Echo anchor safety interlock really meant. The notes on Echo anchor failure mode run to several pages. ORRERY flagged self-repair cascade before anyone else noticed it.

[[chief-aurelio-takeda|Chief Aurelio Takeda]] tells the other side of the story. The same pattern showed up at [[commander-sofia-nakamura|Commander Sofia Nakamura]]. Crew who worked on [[operation-paleglass-v|Operation Paleglass V]] disagreed. This connects to [[orrery|ORRERY]] in ways that are still being argued over.

**Why the echo anchor is kept behind two doors.** ORRERY logged the decision and, unusually, its doubt; the crew learned this the hard way, and wrote it down so the next crew would not have to.

Further reading: *The Trust Ledger* (Adeyemi, 2186).

The ship corrected itself before anyone noticed. Somewhere in the core a subroutine hesitated.
