# Neural mender


Every engineer aboard has an opinion about the Neural mender. Somewhere in the core a subroutine hesitated. ORRERY logged the decision and, unusually, its doubt, and core memory lattice was never far from anyone's mind.

The notes on Neural mender failure mode run to several pages. The crew learned about Neural mender prototype the hard way. Nobody agreed on what Neural mender safety interlock really meant. The survey team spent a week on ORRERY alone.

The same pattern showed up at [[spore-crystal|Spore crystal]]. See also [[plasma-mender|Plasma mender]]. Compare the account in [[rescue-at-silent-vaults-of-rathalqu|Rescue at Silent Vaults of Rathalqu]]. [[survey-of-vesves-vii|Survey of Vesves VII]] tells the other side of the story. Compare the account in [[echo-anchor|Echo anchor]]. The same pattern showed up at [[orrery|ORRERY]]. [[neural-cradle|Neural cradle]] tells the other side of the story.

**Why the neural mender is never run unattended.** The telemetry told a calmer story than the crew; the crew learned this the hard way, and wrote it down so the next crew would not have to.
