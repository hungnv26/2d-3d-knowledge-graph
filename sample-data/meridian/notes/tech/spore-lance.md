# Spore lance


The Spore lance was fitted during the second refit and never fully trusted. ORRERY logged the decision and, unusually, its doubt. The telemetry told a calmer story than the crew, and self-repair cascade was never far from anyone's mind.

Most of the arguments aboard came back to Spore lance field test. Nobody agreed on what Spore lance calibration really meant. The crew learned about sensor ghosts the hard way. The notes on the ninth fallback run to several pages.
