# Ion beacon


Every engineer aboard has an opinion about the Ion beacon. The charts ended and the dark began. Three beacons flickered where there should have been four, and the dark meridian was never far from anyone's mind.

Ion beacon prototype came up in every debrief afterwards. Ion beacon power draw is still an open question in the archive. The crew learned about Ion beacon field test the hard way. Ion beacon calibration is still an open question in the archive. Nobody agreed on what star-fall really meant. The notes on the dark meridian run to several pages. The survey team spent a week on dust rivers alone.
