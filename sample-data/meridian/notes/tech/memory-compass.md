# Memory compass


Every engineer aboard has an opinion about the Memory compass. Somewhere in the core a subroutine hesitated. ORRERY logged the decision and, unusually, its doubt, and the quiet subroutine was never far from anyone's mind.

Memory compass calibration is still an open question in the archive. The survey team spent a week on Memory compass power draw alone. ORRERY flagged Memory compass failure mode before anyone else noticed it. The crew learned about hull telemetry the hard way. Nobody agreed on what self-repair cascade really meant.
