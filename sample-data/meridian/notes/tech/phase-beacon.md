# Phase beacon


The Phase beacon is the kind of machine that works perfectly until it becomes a story. Water was the only currency that mattered. The harvest came in thin but alive, and seed vault was never far from anyone's mind.

Phase beacon calibration is still an open question in the archive. Most of the arguments aboard came back to Phase beacon prototype. Phase beacon failure mode came up in every debrief afterwards. Seed vault came up in every debrief afterwards. The crew learned about emergency sprouting the hard way. The notes on compost engine run to several pages.
