# Tidal mender


The Tidal mender is the kind of machine that works perfectly until it becomes a story. Somewhere in the core a subroutine hesitated. The telemetry told a calmer story than the crew, and machine patience was never far from anyone's mind.

Tidal mender failure mode came up in every debrief afterwards. ORRERY flagged Tidal mender calibration before anyone else noticed it. The crew learned about command handshake the hard way.

Compare the account in [[neural-cradle|Neural cradle]]. The same pattern showed up at [[specialist-freya-quill|Specialist Freya Quill]]. [[spore-loom|Spore loom]] tells the other side of the story. Compare the account in [[incident-report-fold-stall-2189|Incident Report: Fold Stall (2189)]]. This connects to [[choir-moss|Choir Moss]] in ways that are still being argued over. ORRERY logged the decision and, unusually, its doubt. The ship corrected itself before anyone noticed.
