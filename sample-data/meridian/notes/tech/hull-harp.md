# Hull harp


Every engineer aboard has an opinion about the Hull harp. Sickbay went quiet in the way that frightened everyone. Quarantine doors sealed with a sound like a verdict, and phantom symptoms was never far from anyone's mind.

Nobody agreed on what Hull harp field test really meant. Most of the arguments aboard came back to Hull harp calibration. Long-sleep recovery came up in every debrief afterwards.

The same pattern showed up at [[echo-beacon|Echo beacon]]. Crew who worked on [[amber-moss|Amber Moss]] disagreed. The same pattern showed up at [[incident-report-sensor-ghosts-2194|Incident Report: Sensor Ghosts (2194)]]. [[watch-log-2187-108|Watch Log 2187.108]] tells the other side of the story. See also [[lattice-lens|Lattice lens]].

**Why the hull harp is never run unattended.** Quarantine doors sealed with a sound like a verdict; the crew learned this the hard way, and wrote it down so the next crew would not have to.
