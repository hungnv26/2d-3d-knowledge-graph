# Contributing

Thanks for helping. Issues and pull requests are welcome.

- `npm install`, then `npm run demo` to see your change live on the sample archive.
- Before a pull request, run `npm run typecheck && npm run build && npm test && npm run test:e2e`.
- Keep the three pages framework-free. The React and Vue components stay thin wrappers around `mountGraph`.
- Sample data is generated. Change `sample-data/generate.mjs`, never the output.
- Only fictional or public-domain data in this repository, please.
- By contributing you agree that your contribution is licensed under the MIT License of this project.
